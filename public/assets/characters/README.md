# Character image assets

Assets for Aria and Joziel are grouped by use:

- `aria/cards/` and `joziel/cards/`: named program artwork, mapped in `manifest.json`.
- `aria/carousel/` and `joziel/carousel/`: background scenes, listed in playback order in `manifest.json`.

Files use the `.jpg` extension to match their actual JPEG encoding. The uploaded image bytes were retained unchanged, with no resizing or recompression. The repeated Aria source `01-1000239391.png` was identical to `10-1000239391.png` and is included once. This is an asset catalog only; it does not change the card or carousel UI.
